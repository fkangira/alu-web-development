# HTML Advanced

This project is part of my front-end web development journey at ALU.

In this project, I am learning how to build the structure of a real webpage from a design file. For now, I am focusing only on HTML and semantic structure, without adding CSS styling.

The goal is to understand how sections such as the header, navigation, main content, and footer are organized before moving on to styling.
